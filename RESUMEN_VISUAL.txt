🎯 REQUISITOS IMPLEMENTADOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ✅ Identidad y Endpoint de Perfil
   📍 GET /api/usuarios/perfil
   🔒 Solo confía en JWT (req.usuario.id)
   📁 usuarioController.js

2. ✅ RegEx para Validación de Contraseñas
   🔐 Requisito: 8+ chars, 1 mayúscula, 1 número
   📁 src/utils/validadores.js
   🧪 Pruebas: 11/11 pasadas

3. ✅ Tabla de Publicaciones
   🗄️ Foreign Key con ON DELETE RESTRICT
   📁 sql/crear_tabla_publicaciones.sql
   ✨ Índices para optimización creados

4. ✅ Delegación de Identidad al Token
   🔄 Inyecta autor_id desde JWT automáticamente
   📁 publicacionController.js - crear()
   🛡️ Usuario NO puede falsificar autoría

5. ✅ Propiedad de Datos
   🚫 PUT/DELETE: Verifica publicacion.autor_id === req.usuario.id
   💥 Retorna 403 Forbidden si no es dueño
   📁 publicacionController.js

6. ✅ Paginación (LIMIT & OFFSET)
   📄 Parámetros: ?page=X&limit=Y
   ⚡ Cálculo: offset = (page - 1) * limit
   🔢 Máximo: 100 items por página
   📁 publicacionModel.js

7. ✅ Búsqueda Dinámica (LIKE)
   🔍 Parámetro: ?search=termino
   📊 Filtra por: titulo LIKE '%termino%'
   🔗 Compatible con paginación
   📁 publicacionModel.js

8. ✅ Testing Unitario con Jest
   📋 Validadores: 22 casos cubiertos
   🧪 Middleware: 2 casos con mocks
   ✅ Ejecución: npm test
   📁 tests/

9. ✅ Mocks en Express: Middlewares
   🎭 Simula req, res, next sin servidor real
